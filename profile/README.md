## ❓ FAQ

**Do I need to run it as Administrator?**

Yes — admin rights are required for the overlay to attach.

**Is open-source Windows software free?**

Many open-source applications are free to download and use. Some projects offer paid services, optional features, or commercial editions, so check each project's license and terms.

**Can I use these applications on Windows 11?**

Yes. The directory focuses on applications with Windows support, although individual system requirements and supported architectures vary.

**What are some good open-source alternatives to paid software?**

LibreOffice is an office suite alternative, GIMP handles image editing, Blender supports 3D creation, and 7-Zip manages archives.

**Where should I download open-source applications?**

Use the official project website, verified GitHub repository, or trusted package manager. Check release information and select the correct Windows architecture.
